# Tutoriales · Estudio Miguel Alonso

Material de capacitación interna del equipo de Contabilidad, publicado como sitio estático para enlazarlo desde la intranet.

- `index.html` — portal de onboarding de Contabilidad, con el recorrido en cuatro etapas.
- `checklist.html` — checklist del primer mes.
- `glosario.html` — glosario contable-impositivo, con práctica.
- `tutoriales/` — nueve tutoriales en formato video (narración por voz, subtítulos y test final).

Cada tutorial es un único archivo HTML con las imágenes incluidas: se abre en cualquier navegador, sin instalar nada. El progreso de cada persona se guarda solo en su propio navegador.

Las capturas de pantalla tienen difuminados los datos de clientes y de personas.
